🎬 Avaliador de Filmes em Java

Este projeto foi desenvolvido com o objetivo de treinar os principais fundamentos da programação em Java, colocando em prática conceitos essenciais como:

Estruturas condicionais (if / else)

Estruturas de repetição (for)

Lógica de programação

Criação de classes

Métodos públicos e privados

Entrada e saída de dados

📌 Sobre o projeto

O programa permite que o usuário insira informações de um filme, como:

Nome do filme

Ano de lançamento

Gênero

Nota atribuída

Com base nos dados informados, o sistema realiza uma avaliação automática do filme e exibe o resultado na tela, classificando-o conforme a nota inserida.

O objetivo principal do projeto não é apenas o resultado final, mas sim o treinamento da lógica de programação e da organização do código orientado a objetos, simulando um pequeno sistema real.

🛠 Tecnologias utilizadas

Java

Programação Orientada a Objetos (POO)

Console Application

▶ Como executar

Clone o repositório:

git clone https://github.com/RaphaelDalarme/avaliador-de-Filme-em-Java.git


Abra o projeto em sua IDE Java (IntelliJ, Eclipse ou VS Code).

Execute a classe principal (Main.java).
